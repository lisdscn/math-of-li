# 0.11 等价关系 (equivalence relations)

令 S 为给定集合，笛卡尔积 $S\times S=\{(a,b):a\in S,b\in S\}$。
子集 Γ⊆S×S 在 S 上定义一个**关系**；若 (a,b)∈Γ，称 a,b 有关系，记作 a∼b。

若集合 S 上的关系 ∼ 称为**等价关系**当且仅当它满足三条性质：

(a) **自反性**：∀a∈S, a∼a

(b) **对称性**：若 b∼a，则必有 a∼b

(c) **传递性**：若 a∼b，且 b∼c，则 a∼c

集合 S 上的等价关系一一对应 S 中的一个划分。
∀a∈S，定义**等价类**
$$S_a=\{b\in S: b\sim a\}$$
则
要么要么S=⋃a∈SSa;∀a,b∈S, 要么 Sa=Sb, 要么 Sa∩Sb=∅

下表列出矩阵分析中常见的若干等价关系：

| 等价关系 ∼ | A∼B 定义式 
| ---- | ---- |
| 合同（实合同） | A=SBS⊤ |
| 酉合同 | A=UBU⊤ | 
| 复Hermite合同 | A=SBS∗ | 
| 相合相似 | A=SBS−1 |
| 相抵 | A=SBT |  
| 酉相抵 | A=UBV |  
| 对角等价 | A=D1BD2  |
| 相似 | A=SBS−1  |
| 酉相似 | A=UBU∗ |
| 三角等价 | A=LBR

 说明：其中 D1,D2,S,T,L,R 均可逆矩阵，U,V 为酉矩阵，L 下三角矩阵，R 上三角矩阵，D1,D2 为对角矩阵，对应(酉)相抵，三角等价，对角等价；则 A,B 不必为方阵 。

我们希望找到一组代表元，区分各个等价类（称为**典范型**）。

抽象定义：令集合 S 上有等价关系 ∼，子集 C⊆S 称为该等价关系的**典范代表集**，若满足
S=⋃a∈CSa,∀a,b∈C, a≠b⟹Sa∩Sb=∅

元素 a∈S 的典型型是唯一满足 c∈Sa 的元素 c∈C。

设集合 S 上有等价关系 ∼，若 f:S→F 满足 a∼b，就有 f(a)=f(b)，则称 f 为该等价关系的**不变量**。

一族不变量 F 称为**完备不变量系**：∀f∈F 都有 f(a)=f(b)，就能推出 a∼b。
